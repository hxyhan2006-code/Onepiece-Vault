# Onepiece Vault

PWA แบบ mobile-first / offline-first สำหรับ Android ใช้จัดการฟุตเทจอนิเมะที่เก็บในเครื่อง
UI ภาษาไทย ธีมเขียวเข้ม **วิดีโอไม่ถูกอัปโหลดไปไหน** ข้อมูลทั้งหมดอยู่ในเครื่อง (IndexedDB)

## ความสามารถ (MVP)
- **ค้นหา** Scene ตามชื่อฉาก ตัวละคร เหตุการณ์ บันทึก
  - พิมพ์ `ep12` หรือ `ตอน12` เพื่อกรองตามตอน
  - พิมพ์เวลา เช่น `12:30` เพื่อหาฉากที่คร่อมเวลานั้น
  - หลายคำ = ต้องตรงทุกคำ (AND) · กดชิปตัวละคร/เลือกตอนเพื่อกรองเพิ่ม
- **Scene Index**: เพิ่ม/แก้ไข/ลบ Scene (เวลาเริ่ม-จบ ตัวละคร เหตุการณ์ บันทึก) พร้อมปุ่ม “ใช้เวลาวิดีโอเป็นจุดเริ่ม/จบ”
- **นำเข้าวิดีโอในเครื่อง** (1 ไฟล์ต่อตอน) เล่นในแอป แตะ Scene หรือผลค้นหาเพื่อกระโดดไปยังเวลานั้น
- **สำรองข้อมูล JSON**: ส่งออก/นำเข้า (รวมกับข้อมูลเดิม หรือแทนที่ทั้งหมด) พร้อมตรวจความถูกต้องของไฟล์
- **ออฟไลน์เต็มรูปแบบ** ผ่าน Service Worker · ติดตั้งลงหน้าจอหลักได้

## ใช้งานบน Android
PWA ต้องเปิดผ่าน **HTTPS** (หรือ `localhost`) จึงจะติดตั้งและใช้ออฟไลน์ได้
1. โฮสต์โฟลเดอร์นี้เป็นไฟล์ static บน HTTPS (เช่น GitHub Pages, Netlify, Cloudflare Pages) — เป็นเพียงไฟล์แอป ไม่ได้รับข้อมูลผู้ใช้
2. เปิดลิงก์ใน Chrome บนมือถือ → เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงหน้าจอหลัก**
3. เปิดแอปครั้งแรกขณะออนไลน์หนึ่งครั้งเพื่อให้แคชไฟล์ หลังจากนั้นใช้ออฟไลน์ได้
4. ไปที่แท็บ “สำรอง” → กด “ขอให้เบราว์เซอร์ไม่ลบข้อมูลอัตโนมัติ”

## รันบนเครื่องพัฒนา
```bash
npm start          # http://localhost:8080 (ไม่ต้อง npm install — ไม่มี dependency)
npm test           # unit test (node:test)
npm run test:e2e   # ทดสอบใน Chromium ต้องมี playwright ติดตั้งอยู่
```

## โครงสร้าง
```
index.html, manifest.webmanifest, sw.js
css/style.css            ธีมเขียวเข้ม
js/app.js                router (hash) + โหลดข้อมูล
js/db.js                 IndexedDB: episodes / scenes / videos
js/ui.js                 dialog, toast, helper
js/views/                หน้าค้นหา / ตอน / รายละเอียดตอน / ตั้งค่า
js/lib/                  ตรรกะล้วน (timecode, search, backup) — มี unit test
tests/                   unit + e2e
```

## ข้อควรรู้ / ข้อจำกัด
- **วิดีโอถูกคัดลอกเข้าที่เก็บของเบราว์เซอร์** (Android Chrome ยังเข้าถึงไฟล์ต้นฉบับถาวรไม่ได้) จึงกินพื้นที่เพิ่มเท่าขนาดไฟล์ และไฟล์ใหญ่มากอาจเกินโควตา ดูพื้นที่ที่ใช้ได้ในแท็บ “สำรอง”
- **ไฟล์สำรอง JSON ไม่รวมวิดีโอ** ถ้าล้างข้อมูลเบราว์เซอร์/ย้ายเครื่อง ต้องนำเข้าวิดีโอใหม่ แต่ Scene Index กู้คืนได้ครบ
- การเล่นขึ้นกับ codec ที่ Chrome รองรับ (MP4/H.264, WebM ปกติเล่นได้)
- ถ้าแก้ไฟล์แอป ให้เปลี่ยน `VERSION` ใน `sw.js` เพื่อให้เครื่องผู้ใช้อัปเดตแคช
